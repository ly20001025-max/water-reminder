# Contributing

Bug reports, focused fixes, and small improvements are welcome.

## Before opening a pull request

1. Create and activate a Python virtual environment.
2. Install development dependencies with `python -m pip install -e ".[dev]"`.
3. Run `python -m pytest -q` and include relevant tests for behavior changes.
4. Describe the user-visible change and any platform limitation in the pull request.

Keep local environments, runtime data, logs, and generated packaging output out of commits. Do not include personal data or credentials in sample files or issue reports.
